2분 단위로 순서대로 변환합니다. 2시간이면 전사 약 60회이며 문장 다듬기는 별도 호출입니다. API 비용이 발생할 수 있습니다. 창을 닫으면 대기 작업은 멈추고 복구 후 이어서 진행합니다.

3. 참가자와 발언 편집

AI의 발언자 번호는 구간별 번호입니다. 다른 구간의 같은 번호를 같은 사람으로 연결하지 않습니다. 원음을 듣고 각 번호에 참가자를 배정하세요. 문장 수정은 원문과 따로 보관합니다.

4. 검토용 회의록 초안

발언 옆에서 회의록에 넣을 내용을 선택하세요. 선택한 수정 문장과 구간 번호로 초안을 만듭니다. 결정 여부·담당자·기한은 원음을 확인해 직접 확정하세요.

TXT·JSON·WAV 다운로드 파일은 암호화되지 않습니다. JSON에는 음성이 포함되지 않습니다. 기관의 승인된 보관 위치에 저장하세요. 자동 게시·결재 제출은 하지 않습니다.
